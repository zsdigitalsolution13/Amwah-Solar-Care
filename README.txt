# AMWAH Solar Care — Website Demo

This is a complete responsive front-end demo intended as a visual/structural reference when rebuilding the website in WordPress.

## Files
- index.html — full page structure and content
- style.css — responsive design
- script.js — mobile menu, scroll reveal and demo form interaction

## WordPress conversion map
- Header/navigation → WordPress theme header or Elementor Header
- Hero → Elementor/ Gutenberg section
- About → two-column section
- Products → WooCommerce product/category cards
- Services → service cards
- Projects → portfolio/gallery
- Contact form → WPForms / Contact Form 7 / Fluent Forms
- Footer → WordPress footer widgets

## Important
The supplied PDF contains only a title and a note saying it is a visual reference; it does not contain an actual website screenshot/layout. Therefore this demo is a professional AMWAH Solar Care starting design, not a pixel-for-pixel recreation of the PDF.

Replace placeholder phone, email and address with the actual business details.
